# Weather App

This is a simple Python weather application that fetches weather information for a city using the wttr.in weather service.

## Features

* Get current weather for any city
* Uses Python requests library
* Includes error handling

## Requirements

* Python 3
* requests library

## Installation

pip install requests

## Run the Program

python weather.py

## Example

Enter city name: London
